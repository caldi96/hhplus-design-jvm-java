이커머스 서비스 요구사항 분석서

1. 유저 관리
- 회원가입
- 프로필 조회

2. 상품 조회
- 카테고리별 조회
- 검색 기능(상풍명, 카테고리)
- 페이징 처리(20개씩)
- 정렬 (가격순, 인기순(가장 많이 팔린것), 최신순)
- 상품 찜하기 (위시 리스트)
- 최근 본 상품 목록

3. 상품 상세정보
- 상품 이미지, 설명, 가격, 재고 표시
- 리뷰 및 평점 조회

4. 상품 관리
- 상품 등록/삭제
- 상품명 변경
- 재고 관리
- 가격 변경

5. 장바구니 관리
- 상품 추가
- 선택 삭제
- 전체 삭제 (장바구니 비우기)
- 수량 변경
- 장바구니 조회
- 품절 상품 자동 표시

6. 주문 생성
- 즉시 주문
- 장바구니에서 주문
- 배송지 정보 입력
- 주문 내역 저장
- 주문 상태 변경

7. 선착순 쿠폰 발급
- 발급 수량 제한 (예: 선착순 100명)
- 발급 시작 시간 설정
- 1인당 1개 발급 제한
- 실시간 잔여 수량 표시
- 대기열 처리 (트래픽 폭주 대응)

8. 쿠폰 관리
- 쿠폰 조회
- 정액 할인 쿠폰 (예: 10,000원 할인, 포인트와 함께 사용시 포인트 먼저 차감)
- 정률 할인 쿠폰 (예: 30% 할인, 포인트와 함께 사용시 포인트 먼저 차감 후 정률 할인 적용)
- 최대 할인 금액 설정 (정률 쿠폰)
- 정액 할인 쿠폰 사용시 총 금액이 할인 금액보다 낮을 경우 전액 할인 0원
- 쿠폰 유효기간 지났을 시 만료
- 사용된 쿠폰 시 만료

9. 동시성 제어
- 중복 발급 방지
- 수량 초과 발급 방지
- 동시 요청 처리 (Redis 활용)
- 발급 실패 시 즉시 알림

10. 결제 처리
- PG사 연동 (Mock)
- 결제 방법 입력
- 결제 검증
- 결제 실패 시 롤백
- 결제 상태 변경

11. 주문 관리
- 주문 내역 조회
- 주문서 임시 저장
- 주문 취소 (취소 사유 입력, 주문 단계에 따른 조건부 취소)
- 부분 주문 취소
- 주문 취소 확정 (환불, 쿠폰, 포인트 원복)
- 환불 요청 (환불 사유 입력)
- 부분 환불 요청
- 환불 확정 (사유에 따른 배송비 및, 쿠폰 원복)
- 주문 상태 변경
- 상품 반품 요청 (사유 입력)
- 상품 반품 결정 (사유에 따른 배송비 및, 쿠폰 원복)

12. 배송 관리
- 배송 등록
- 배송 상태 변경

13. 리뷰 관리
- 리뷰 조회 (최신순, 평점순, 도움순 정렬)
- 리뷰 작성 (구매 확정 후, 별점)
- 리뷰 수정
- 리뷰 삭제 (댓글이 하나도 없으면 삭제, 있으면 삭제되었습니다로 놔두기)
- 리뷰 이미지 첨부
- 리뷰 도움됨(추가/삭제)
- 리뷰 신고 기능
- 베스트 리뷰 선정
- 리뷰 답글
- 리뷰 답글 수정
- 리뷰 답글 삭제(답글 삭제 시 모든 답글과 원 대댓글이 삭제되어 있을시 모두 삭제)

14. 포인트 적립 및 관리
- 구매 적립 (1 ~ 5%)
- 리뷰 작성 포인트
- 포인트 사용 (결제 시, 정책 선택)
- 포인트 유효 기간
- 포인트 사용/적립 내역 저장
- 포인트 사용/적립 내역 조회
